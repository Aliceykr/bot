# Bot — ИИ-голосовой ассистент ESP32-S3 и эмулятор Game Boy

> 🌐 Язык: [简体中文](README.md) | [English](README.en.md) | [Français](README.fr.md) | [Español](README.es.md) | **Русский** | [العربية](README.ar.md)

Встраиваемый проект на ESP32-S3 на базе ESP-IDF + LVGL. Включает WiFi, запрос погоды, чат с ИИ, онлайн/офлайн распознавание речи, синтез речи, эмулятор Game Boy с аудио, BLE-провизионирование и дистанционное управление музыкой, музыкальный плеер MicroSD (WAV + MP3), регулировку громкости и управление умными устройствами Bemfa Cloud. Графический интерфейс TFT LCD с поворотным энкодером и матрицей кнопок.

| Строка/Столбец | GPIO41 (C0) | GPIO42 (C1) | GPIO47 (C2) |
|----------------|-------------|-------------|-------------|
| GPIO1 (R0)  | B | ВВЕРХ | A |
| GPIO2 (R1)  | ВЛЕВО | EXIT | ВПРАВО |
| GPIO14 (R2) | SELECT | ВНИЗ | START |

### MPU6050 (I2C_NUM_0)

| Функция | ESP32-S3 | MPU6050 |
|---------|----------|---------|
| SDA | GPIO20 | SDA |
| SCL | GPIO7  | SCL |

I2C 400 кГц, диапазон ±2 g, DLPF 44 Гц. Инициализируется только для игры 2048, освобождается при выходе. Определение наклона с гистерезисом (ENTER 0,30 g, EXIT 0,15 g) + блокировка направления.

### Карта MicroSD (SPI3_HOST)

| Функция | ESP32-S3 |
|---------|----------|
| CS   | GPIO0  |
| MOSI | GPIO8  |
| SCK  | GPIO18 |
| MISO | GPIO21 |

> Примечание: CS использует GPIO0 (кнопка Boot); не удерживать при включении питания.

## Функциональность

### 1. Главное меню

При загрузке отображается список функций. Навигация поворотным энкодером, подтверждение нажатием:

- **Мониторинг окружающей среды** — Заглушка (в разработке)
- **Погода и дата** — HTTP-запрос погоды в реальном времени
- **Игры** — Встроенная игра 2048 + эмулятор Game Boy (ROM из `/sdcard/rom/`)
- **Чат-ассистент** — Экранная клавиатура, вызов API LLM, прокручиваемая история
- **Голосовой ассистент** — Запись → Baidu ASR → LLM → Baidu TTS → воспроизведение
- **Голосовая команда** — Офлайн-распознавание ESP-SR (переключатель вкл/выкл, без отдельного экрана)
- **Bluetooth** — Провизионирование WiFi через BLE + дистанционное управление музыкой
- **Музыка** — Воспроизведение WAV/MP3 из `/sdcard/music/`
- **Громкость** — Ползунок 0–100 %, логарифмическая кривая, сохранение в NVS
- **Умные устройства** — Управление Bemfa Cloud: список, явная отправка on/off

### 2. Эмулятор Game Boy

- На основе Walnut-CGB (высокопроизводительная переработка Peanut-GB), поддержка DMG + CGB
- Нативное разрешение 160x144, масштабирование 1,5x до 240x216
- Асинхронный DMA-рендеринг с двойной буферизацией при 80 МГц SPI
- ROM загружаются с SD-карты в PSRAM (до 4 МБ)
- Встроенная игра 2048 всегда видна в начале списка
- Управление наклоном MPU6050 для 2048 (сосуществует с кнопками)
- Полный ввод для игры через матрицу 3x3 (A/B/направления/START/SELECT/EXIT)
- WiFi и BLE приостанавливаются при входе в игру, восстанавливаются при выходе

### 3. Голосовой ассистент (онлайн)

```
Нажатие кнопки → запись INMP441 (16 кГц, 16 бит моно, макс 10 с, PSRAM)
    ↓
API Baidu ASR (мандаринский)
    ↓
Распознанный текст → LLM (совместимый с OpenAI, max_tokens=128)
    ↓
API Baidu TTS (потоковый WAV PCM)
    ↓
Воспроизведение MAX98357A (RingBuffer + I2S DMA)
```

### 4. Голосовая команда (ESP-SR офлайн)

MultiNet7 ESP-SR, 9 команд с префиксом "打开" (открыть):

| ID | Команда | Функция | Требует WiFi |
|----|---------|---------|--------------|
| 1 | Открыть мониторинг среды | Мониторинг | Нет |
| 2 | Открыть погоду и дату | Погода | Да |
| 3 | Открыть игры | Игры | Нет |
| 4 | Открыть чат-ассистент | Чат | Да |
| 5 | Открыть голосовой ассистент | ASR+LLM+TTS | Да |
| 6 | Открыть Bluetooth | BLE | Нет |
| 7 | Открыть музыку | Музыка | Нет |
| 8 | Открыть громкость | Громкость | Нет |
| 9 | Открыть умные устройства | Bemfa | Да |

Конечный автомат с 5 состояниями (IDLE / STARTING / ACTIVE / DISPATCH / STOPPING). Все переходы состояний выполняются в потоке LVGL.

### 5. BLE-провизионирование и управление музыкой

- Подключение BLE к "ESP32-Bot" (Сервис 0xFFE0, Характеристика 0xFFE1)
- Отправить `SSID_имя password_пароль` для настройки WiFi
- Музыкальные команды: `/music on`, `/music off`, `/<индекс>`

### 6. Умные устройства (Bemfa Cloud)

- **Список**: GET `/vb/api/v2/allTopic`
- **Состояние устройства**: GET `/vb/api/v2/topicInfo` (< 200 Б, быстрее полного списка)
- **Отправка**: POST `/va/postJsonMsg` с `on` / `off`
- **UX**: клик по устройству → диалог "Включить / Выключить / Отмена" → немедленное оптимистичное обновление → проверка состояния через 1,2 с

## Быстрый старт

### Требования

- ESP-IDF v5.4+ (рекомендуется v5.4.3)
- Целевой чип ESP32-S3
- Карта MicroSD (FAT32)

### Шаги

```bash
git clone <repo-url>
cd bot
cp user/asr_config.h.example user/asr_config.h
cp user/model_config.h.example user/model_config.h
cp user/bemfa_config.h.example user/bemfa_config.h
# Заполнить API-ключи в каждом файле
idf.py set-target esp32s3
idf.py build
# Linux:
idf.py -p /dev/ttyUSB0 -b 2000000 flash
# Windows:
idf.py -p COM5 -b 2000000 flash
```

Структура SD-карты:
```
/sdcard/
├── rom/     # файлы .gb / .gbc
└── music/   # файлы .wav / .mp3
```

## Бюджет памяти (ESP32-S3 N16R8)

### Flash (16 МБ)
| Содержимое | Размер |
|------------|--------|
| Полная прошивка | ~4,7 МБ |
| Раздел модели ESP-SR | 3 МБ |
| Резервный раздел OTA | 6,5 МБ |

### PSRAM (8 МБ Octal)
| Использование | Размер |
|---------------|--------|
| Буфер записи ASR | ~320 КБ (освобождается после распознавания) |
| Буфер HTTP-ответа | 4–32 КБ (освобождается после каждого вызова) |
| Данные ROM (во время игры) | 32 КБ – 2 МБ |
| Свободно | **~7 МБ** |

### Внутренняя DRAM (~338 КБ)
| Использование | Размер |
|---------------|--------|
| Двойной буфер LVGL | ~32 КБ |
| RingBuffer динамика | 64 КБ |
| WiFi / LwIP / mbedTLS | ~100 КБ |
| Свободно | **~107 КБ** |
