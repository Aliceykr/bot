# Bot — مساعد صوتي ذكي ESP32-S3 ومحاكي Game Boy

> 🌐 اللغة: [简体中文](README.md) | [English](README.en.md) | [Français](README.fr.md) | [Español](README.es.md) | [Русский](README.ru.md) | **العربية**

مشروع مدمج على ESP32-S3 مبني على ESP-IDF + LVGL، يدمج WiFi واستعلام الطقس ودردشة الذكاء الاصطناعي والتعرف على الكلام عبر الإنترنت/دون اتصال وتوليف الكلام ومحاكي Game Boy مع الصوت وتوفير BLE والتحكم عن بُعد في الموسيقى ومشغل موسيقى MicroSD (WAV + MP3) والتحكم في مستوى الصوت والتحكم في الأجهزة الذكية عبر Bemfa Cloud. واجهة رسومية TFT LCD مع مشفر دوار ومصفوفة مفاتيح.

| المكوّن | الطراز / المواصفات | ملاحظات |

## الميزات

### 1. القائمة الرئيسية

عند التشغيل تظهر قائمة الميزات. التنقل بالمشفر الدوار، التأكيد بالضغط:

- **مراقبة البيئة** — عنصر نائب (قيد التطوير)
- **الطقس والتاريخ** — جلب بيانات الطقس عبر HTTP في الوقت الفعلي
- **الألعاب** — لعبة 2048 المدمجة + محاكي Game Boy (ROM من `/sdcard/rom/`)
- **مساعد الدردشة** — لوحة مفاتيح على الشاشة، استدعاء API LLM، سجل قابل للتمرير
- **المساعد الصوتي** — تسجيل → Baidu ASR → LLM → Baidu TTS → تشغيل
- **الأوامر الصوتية** — تعرف ESP-SR دون اتصال (مفتاح تشغيل/إيقاف، بدون شاشة مخصصة)
- **البلوتوث** — توفير WiFi عبر BLE + التحكم عن بُعد في الموسيقى
- **الموسيقى** — تشغيل WAV/MP3 من `/sdcard/music/`
- **مستوى الصوت** — شريط تمرير 0–100%، منحنى لوغاريتمي، محفوظ في NVS
- **الأجهزة الذكية** — التحكم في Bemfa Cloud: قائمة، إرسال on/off صريح

### 2. محاكي Game Boy

- مبني على Walnut-CGB (إعادة كتابة عالية الأداء لـ Peanut-GB)، يدعم DMG + CGB
- دقة أصلية 160x144، تكبير 1.5x إلى 240x216
- عرض DMA غير متزامن بتخزين مؤقت مزدوج عند 80 ميغاهرتز SPI
- تُحمَّل ROM من بطاقة SD إلى PSRAM (حتى 4 ميغابايت)
- لعبة 2048 المدمجة دائمًا مرئية في أعلى القائمة
- التحكم بالإمالة MPU6050 للعبة 2048 (يتعايش مع الأزرار)
- إدخال كامل للعبة عبر مصفوفة 3x3 (A/B/اتجاهات/START/SELECT/EXIT)
- WiFi وBLE معلقان عند دخول اللعبة، يُستعادان عند الخروج

### 3. المساعد الصوتي (عبر الإنترنت)

```
ضغط الزر → تسجيل INMP441 (16 كيلوهرتز، 16 بت أحادي، حتى 10 ثوانٍ، PSRAM)
    ↓
Baidu ASR API (الماندرين)
    ↓
النص المُعرَّف → LLM (متوافق مع OpenAI، max_tokens=128)
    ↓
Baidu TTS API (WAV PCM متدفق)
    ↓
تشغيل MAX98357A (RingBuffer + I2S DMA)
```

### 4. الأوامر الصوتية (ESP-SR دون اتصال)

MultiNet7 ESP-SR، 9 أوامر بادئة بـ "打开" (فتح):

| المعرّف | الأمر | الوظيفة | يتطلب WiFi |
|---------|-------|---------|------------|
| 1 | فتح مراقبة البيئة | المراقبة | لا |
| 2 | فتح الطقس والتاريخ | الطقس | نعم |
| 3 | فتح الألعاب | الألعاب | لا |
| 4 | فتح مساعد الدردشة | الدردشة | نعم |
| 5 | فتح المساعد الصوتي | ASR+LLM+TTS | نعم |
| 6 | فتح البلوتوث | BLE | لا |
| 7 | فتح الموسيقى | الموسيقى | لا |
| 8 | فتح مستوى الصوت | الصوت | لا |
| 9 | فتح الأجهزة الذكية | Bemfa | نعم |

آلة حالات بـ 5 حالات (IDLE / STARTING / ACTIVE / DISPATCH / STOPPING). جميع انتقالات الحالة تتم في خيط LVGL.

### 5. توفير BLE والتحكم في الموسيقى

- الاتصال بـ BLE بـ "ESP32-Bot" (الخدمة 0xFFE0، الخاصية 0xFFE1)
- إرسال `SSID_الاسم password_كلمةالمرور` لتهيئة WiFi
- أوامر الموسيقى: `/music on`، `/music off`، `/<الرقم>`

### 6. الأجهزة الذكية (Bemfa Cloud)

- **القائمة**: GET `/vb/api/v2/allTopic`
- **حالة جهاز واحد**: GET `/vb/api/v2/topicInfo` (< 200 بايت، أسرع من القائمة الكاملة)
- **الإرسال**: POST `/va/postJsonMsg` مع `on` / `off`
- **تجربة المستخدم**: النقر على جهاز → حوار "تشغيل / إيقاف / إلغاء" → تحديث فوري متفائل → التحقق من الحالة بعد 1.2 ثانية

## البدء السريع

### المتطلبات

- ESP-IDF v5.4+ (يُوصى بـ v5.4.3)
- الهدف ESP32-S3
- بطاقة MicroSD (FAT32)

### الخطوات

```bash
git clone <repo-url>
cd bot
cp user/asr_config.h.example user/asr_config.h
cp user/model_config.h.example user/model_config.h
cp user/bemfa_config.h.example user/bemfa_config.h
# ملء مفاتيح API في كل ملف
idf.py set-target esp32s3
idf.py build
# Linux:
idf.py -p /dev/ttyUSB0 -b 2000000 flash
# Windows:
idf.py -p COM5 -b 2000000 flash
```

هيكل بطاقة SD:
```
/sdcard/
├── rom/     # ملفات .gb / .gbc
└── music/   # ملفات .wav / .mp3
```

## ميزانية الذاكرة (ESP32-S3 N16R8)

### الفلاش (16 ميغابايت)
| المحتوى | الحجم |
|---------|-------|
| البرنامج الثابت الكامل | ~4.7 ميغابايت |
| قسم نموذج ESP-SR | 3 ميغابايت |
| قسم OTA الاحتياطي | 6.5 ميغابايت |

### PSRAM (8 ميغابايت Octal)
| الاستخدام | الحجم |
|-----------|-------|
| مخزن تسجيل ASR | ~320 كيلوبايت (يُحرَّر بعد التعرف) |
| مخزن استجابة HTTP | 4–32 كيلوبايت (يُحرَّر بعد كل استدعاء) |
| بيانات ROM (أثناء اللعب) | 32 كيلوبايت – 2 ميغابايت |
| متاح | **~7 ميغابايت** |

### DRAM الداخلية (~338 كيلوبايت)
| الاستخدام | الحجم |
|-----------|-------|
| المخزن المؤقت المزدوج LVGL | ~32 كيلوبايت |
| RingBuffer السماعة | 64 كيلوبايت |
| WiFi / LwIP / mbedTLS | ~100 كيلوبايت |
| متاح | **~107 كيلوبايت** |
